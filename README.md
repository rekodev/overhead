# Overhead

A calm, keyboard-first HUD for Claude Code on macOS. It shows every session at the top of your screen and lets you approve requests, answer questions, review plans, reply and jump back to the right terminal pane, all without leaving what you're doing.

Early development. Nothing to install yet.

## Development

Requires Rust (stable), Node 24 and pnpm.

```sh
pnpm install
pnpm tauri dev
```
